Release notes

What changed in 1.4.4

  • Capture a master, parts, or both from your DAW with the WavRead Bridge plugin.
  • Measure delay, reverb decay, and tone changes introduced by the master bus when the evidence is available.
  • See true peak and clipping for each supplied or captured part.
  • Read the full usage guide inside WavRead and install verified updates from Settings.
